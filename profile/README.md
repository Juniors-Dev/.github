## 🤝 Our Ethos
**Communication**
We value clear, honest communication.
There are no dumb questions — ever.
It’s always better to ask than to stay stuck. Speak up, whether it’s a technical question, an idea, or feedback.

**Transparency**
Be open about what you're working on, what you're stuck on, or if you need to step back for a bit.
We’re all learning — no one will judge you for needing help or being human.

**Initiative**
You don’t need permission to contribute.
Start a thread, sketch an idea, build a prototype.
Done is better than perfect, and trying is better than waiting.

## 🔁 Workflow & Tools
### 🧩 Process
We follow an MVP-first, lightweight, and collaborative process:
1. **Ideation & Planning** — brainstorm, vote, define goals and data structures
2. **Design** — Figma-based MVP UI/UX by our design squad
3. **Frontend & Backend** — APIs, dummy data, integration
4. **Deploy & Feedback** — live testing and iteration

### 🛠 Tools We Use
- 💬 Discord — communication hub with team channels
- 📌 Jira — task tracking, user stories, agile board
- 🎨 Figma/FigJam — for collaborative planning and design
- 👨‍💻 GitHub — code, issues, and project organization
